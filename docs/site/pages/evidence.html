Evidence

A chip project climbs one ladder: tested RTL, then synthesis, layout, timing, a shuttle, a fabricated chip, a measured chip. Each rung below says whether it has been reached and names the command or tool run that showed it. A rung without evidence is marked so, even when it is expected to pass.

Labels: measured a tool run produced it · estimate a number from before the step that settles it · failed run and did not pass · not yet not run or not reachable yet.

Check it yourself

make -C test sim                          # every RTL suite, including the tour
make -C test act                          # the official RISC-V tests
make -C test area                         # cell area with the real sky130 library
python3 docs/tools/atlas.py --check       # the atlas still matches the RTL
python3 docs/tools/traces.py --check      # the tours still match a fresh simulation
python3 docs/tools/check_site.py          # the site, its models and its pinout
